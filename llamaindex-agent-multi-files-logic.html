三、核心函数详解

3.1 setup_llm_and_embedding()

作用：配置 LLM 和 Embedding 模型，使用 DashScope 服务。

flowchart TD S1[读取环境变量 DASHSCOPE_API_KEY] --> S2{API Key 有效?} S2 -->|否| S3[raise ValueError] S2 -->|是| S4[实例化 DashScope LLM] S4 --> S5[参数: deepseek-v3, temp=0.7, top_p=0.8] S5 --> S6[实例化 DashScopeEmbedding] S6 --> S7[模型: TEXT_EMBEDDING_V2] S7 --> S8[返回 llm, embed_model]

3.2 load_documents_and_create_index()

作用：加载文档并创建向量索引，支持索引缓存复用。

flowchart TD L1[检查 ./storage 是否存在] --> L2{存在?} L2 -->|是| L3[StorageContext.from_defaults] L3 --> L4[load_index_from_storage] L4 --> L5{成功?} L5 -->|是| L6[返回已加载的 index] L5 -->|否| L7[捕获异常，继续创建] L2 -->|否| L8[检查 ./docs 目录] L7 --> L8 L8 --> L9{docs 存在?} L9 -->|否| L10[返回 None] L9 -->|是| L11[SimpleDirectoryReader.load_data] L11 --> L12[VectorStoreIndex.from_documents] L12 --> L13[index.storage_context.persist] L13 --> L6

3.3 create_agent()

作用：基于索引创建 ReAct 智能体及检索工具。

flowchart TD A1[index] --> A2[as_retriever similarity_top_k=5] A1 --> A3[as_query_engine similarity_top_k=5] A3 --> A4[retrieve_documents 函数] A4 --> A5[内部调用 query_engine.query] A5 --> A6[FunctionTool.from_defaults] A6 --> A7[ReActAgent] A7 --> A8[tools: retrieve_tool] A7 --> A9[llm] A7 --> A10[system_prompt: 助手角色说明] A7 --> A11[返回 agent, retriever]

四、关键组件说明

组件 说明
VectorStoreIndex 向量索引，将文档切分并向量化存储，支持相似度检索
ReActAgent 推理-行动智能体，按 Think -> Action -> Observe 循环决策
retrieve_documents 工具函数，封装 query_engine.query，供 Agent 调用检索文档
retriever 检索器，返回 top-k 相似节点，用于调试展示召回内容
query_engine 查询引擎，检索 + LLM 生成，返回完整回答
